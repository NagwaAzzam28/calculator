# calculator

A simple browser-based calculator capable of performing and chaining multiple arithmetic operations. It supports both mouse and keyboard input.

This project was built as the final project of **The Odin Project Foundations** course.

## Features :

- Perform addition, subtraction, multiplication, and division.
- Chain multiple operations without pressing equals after every operation.
- Supports both mouse and keyboard input.
- Clear (`AC`) and delete (`⌫`) functionality.
- Decimal number support.

## skills practiced :

- DOM manipulation.
- Event delegation.
- State management.
- Keyboard event handling.
- Writing guard clauses and handling edge cases.
- Data attributes (`data-*`) for mapping UI interactions.
